Comma

Benutzerhandbuch · Version 1.0 · Windows, VST3 und Standalone

1. Willkommen

Comma ist ein Synthesizer, der um eine Idee herum gebaut ist: Jede gespielte Note ist ein Akkord aus bis zu acht Stimmen. Jede Stimme spielt die Note in ihrem eigenen Verhältnis (1 = die Note, 2 = eine Oktave höher, 1,5 = eine Quinte ...), und jede Stimme hat ihre eigene Engine: additive Teiltöne, ein angeschlagener Körper, ein chaotisches System, Logikgatter, Wavetables, Grains, Rauschen. Um die Stimmen herum liegen Filter und EQs, eine Effektkette, deren Reihenfolge Sie frei ändern können, und ein Modulationssystem mit 32 Quellen, einer Matrix mit 32 Verbindungen, acht Makros und einem XY-Pad.

Comma ist monophon: Es spielt immer nur eine Note (die zuletzt gehaltene Taste hat Vorrang). Der Akkord entsteht aus den acht Stimmen und ihren Verhältnissen, nicht aus mehreren gedrückten Tasten. So bleiben die acht Engines bezahlbar, und der Akkord ist in sich immer rein gestimmt.

Warum „Comma“

In der Musiktheorie ist ein Komma ein winziges Intervall: der Rest, der immer übrig bleibt, wenn man reine Intervalle übereinanderschichtet. Zwölf reine Quinten übersteigen sieben Oktaven um das pythagoreische Komma (etwa 23,5 Cent); vier reine Quinten übersteigen eine reine große Terz um das syntonische Komma (81/80, etwa 21,5 Cent). Die gleichstufige Stimmung verbirgt diese Abweichungen, indem sie sie auf die zwölf Halbtöne verteilt. Comma arbeitet auf der anderen Seite: Seine Verhältnisse können rein sein (der goldene Würfel der Ratio-Presets würfelt Akkorde in reinen Intervallen), seine Dissonanzschaltung kann die Teiltöne auf ein Raster von 12 bis 31 Tönen pro Oktave legen, und schon wenige Cent Verstimmung zwischen den Stimmen genügen, damit ein Akkord schwebt.

Fahren Sie mit der Maus über einen Regler, um zu sehen, was er bewirkt: Die Schaltfläche ? oben schaltet diese Hinweise ein und aus. Jeder Regler in diesem Handbuch hat seinen Hinweis im Plugin.

2. Installation und Lizenz

Was das Installationsprogramm tut

  • Comma.vst3 wird in den gemeinsamen VST3-Ordner (C:\Program Files\Common Files\VST3) installiert, in dem jeder Host sucht.
  • Comma.exe, die Standalone-Anwendung, wird in Program Files\HavFun Company\Comma installiert, mit einer Verknüpfung im Startmenü (eine Desktop-Verknüpfung ist optional).
  • Die Werksbank (Presets, Wavetables, Samples, Filter- und EQ-Kurven ...) wird in Documents\Comma abgelegt. Das Installationsprogramm überschreibt nie eine bereits vorhandene Datei und entfernt diesen Ordner bei der Deinstallation nie: Von nun an sind das Ihre Klänge.

Comma läuft unter 64-Bit-Windows. Formate: VST3 und Standalone. Das Plugin ist ein Instrument: Es braucht MIDI vom Host. Außerdem hat es einen optionalen Stereo-Sidechain-Eingang, den der Sidechain-Effekt (Modus Input) und die Modulationsquelle Follow nutzen; aktivieren Sie ihn im Routing Ihres Hosts.

Testphase und Aktivierung

Comma läuft ab dem ersten Start 14 Tage lang ohne Einschränkung. Nach Ablauf der Testphase wird der Klang ausgeblendet, und das Lizenzfenster verdeckt die Oberfläche, bis Sie aktivieren. Eine Neuinstallation startet die Testphase nicht neu.

  1. Comma kaufen: Menu → License... → Buy Comma öffnet den Shop.
  2. Sie erhalten einen Lizenzschlüssel per E-Mail. Fügen Sie ihn in das Lizenzfenster ein und klicken Sie auf Activate. Dafür ist einmalig eine Internetverbindung nötig.
  3. Ein Schlüssel gilt für 3 Computer. Deactivate gibt diesen Computer frei, damit Sie den Schlüssel auf einem anderen nutzen können.

Nach der Aktivierung arbeitet Comma offline. Es prüft den Schlüssel gelegentlich beim Shop; offline zu sein ändert daran nichts. Übertragen werden nur der Schlüssel und ein anonymer Fingerabdruck des Computers, sonst nichts. Das Lizenzfenster zeigt den Status: die verbleibenden Tage der Testphase oder „Activated on this computer“ mit teilweise maskiertem Schlüssel.

3. Schnellstart

  1. Laden Sie Comma auf eine Instrumentenspur (oder öffnen Sie die Standalone-Version) und spielen Sie eine Note: Sie hören das Startpreset DeFaUlT.
  2. Klicken Sie auf die Pfeile der Presetliste oben oder auf den goldenen Würfel daneben, um andere Presets zu hören.
  3. Öffnen Sie den Tab Synthesis: Jede Zeile ist eine Stimme. Ändern Sie die Ratio einer Stimme, und der Akkord ändert sich. Klicken Sie auf das Engine-Feld (Add, Wave ...), um zu wählen, was die Stimme ist.
  4. Klicken Sie auf die Nummer einer Stimme, um sie stummzuschalten, auf ihren Kopfhörer, um sie solo zu hören.
  5. Öffnen Sie FX, schalten Sie einen Effekt mit dem Symbolfeld links auf seiner Leistenschaltfläche ein und ziehen Sie die Schaltfläche nach oben oder unten, um die Reihenfolge der Effekte zu ändern.
  6. Ziehen Sie eine Mod 1-Schaltfläche (unten rechts) auf einen beliebigen Drehregler: Dieser Regler bewegt sich nun mit Mod 1. Fahren Sie mit der Maus über die Mod-Schaltfläche, um alles zu sehen, was sie bewegt.
  7. Speichern Sie Ihren Klang: Öffnen Sie das Menü der Presetliste und wählen Sie Save As, oder verwenden Sie den Tab Presets.

4. Das Fenster

  1. Haupt-Tabs: Synthesis (die acht Stimmen: ihre Engines und ihre Seiten), EQ's/Filters (EQ A-D, F1-F4, Modal, Warmth), Modulation (die Modulationsquellen und die Matrix), FX (die Effektleiste), Presets (der Preset-Browser).
  2. Stimmenseiten (Tab Synthesis): Engine, Attack, PM, Diss, Warp, Mangle, Pluck, Motion, Spectron, Capture, Env, Punch. Sie folgen dem Signal von links nach rechts. Das Symbol vor dem Namen einer Seite leuchtet, wenn diese Seite bei mindestens einer Stimme etwas bewirkt.
  3. Scale: zieht die gespielten Noten auf eine Skala (siehe Spielen).
  4. ?: schaltet die Hinweise ein oder aus.
  5. Die Presetliste, ihre Pfeile und ihre beiden Würfel.
  6. Die Ratio-Presets: Akkorde für die acht Stimmen, mit eigenen Würfeln. Daneben Mutate und seine Stärke (siehe Die Würfel).
  7. Menu: Farbschema, Fenstergröße, Lizenz; in der Standalone-Anwendung ihr Tempo.
  8. Die Stimmenköpfe: Verhältnis, Verstimmung, Panorama, Engine, Mute, Solo, Würfel und ein Live-Spektrum für jede Stimme. Die Spalte lässt sich bis V8 scrollen.
  9. Der Stimmenkörper: die unter 2 gewählte Seite, für jede Stimme.
  10. Der Rahmen Global / Sub: Tonhöhe, Anschlagdynamik, Pegel in die Effekte, Stimmenfader, Master-Hüllkurve, Glide; oder der Sub-Oszillator.
  11. Die Mod-Kurzwahlen: Ziehen Sie eine davon auf einen beliebigen Regler, um ihn zu modulieren.
  12. Der Leistenumschalter: M Makros, K Tastatur, C Akkordfolge.
  13. Die Makros M1-M8 (oder die Tastatur, oder die Akkordschritte).
  14. Die Ausgangsspalte: Master-Lautstärke, Limiter, Pegelanzeige, CPU, Rec.

Die Fenstergröße lässt sich durch Ziehen an der Ecke ändern (50 bis 300 %) oder über Menu → Window Size (75, 100, 125, 150 oder 200 %). Menu → Theme ändert die Farbe: Cyan, Emerald, Azure, Violet oder Silver. Beides wird auf diesem Computer gespeichert, nicht in den Presets.

In der Standalone-Anwendung stellt Menu → Standalone Tempo das Tempo für alles ein, was sich daran ausrichtet (LFOs, Delay, Taps, Hüllkurven mit SYNC), wenn kein Host eines vorgibt: 20 bis 300 BPM, auf diesem Computer gespeichert. In einem Host gilt das Tempo des Hosts.

6. Die acht Stimmen

Jede Stimme spielt die gehaltene Note, multipliziert mit ihrem Verhältnis. Die acht Stimmen zusammen bilden den Akkord. Eine Stimme mit der Engine Empty ist stumm und kostet nichts.

Den Pegel jeder Stimme regelt ihr Fader im Rahmen Global, mit Marken bei 0 und -6 dB.

Pegel: Sie verwalten die Verstärkung

In Comma bedeutet 0 dB „der Pegel ändert sich nicht“. Wie an einem Mischpult senkt nichts den Pegel hinter Ihrem Rücken: Zwei Stimmen mit gleichem Pegel sind lauter als eine, das Stummschalten einer Stimme hebt die anderen nicht an, und acht Stimmen mit vollem Pegel müssen Sie selbst absenken. Eine Schutzstufe ganz am Ende des Ausgangs rundet nur ab, was übersteuern würde; sie ist keine Pegelregelung.

Die Aussteuerungsreserve ist also sichtbar, in den Einstellungen. Ein neuer Klang beginnt mit dem Fader jeder Stimme auf -6 dB, Gain (Pegel in die Effekte) auf -3 dB und Master auf -9 dB. Ein Doppelklick bringt diese drei auf diese Werte zurück. Presets behalten ihre eigenen Pegel.

Ratio-Presets

Die Liste oben rechts, (Ratio presets), speichert nur Verhältnisse: einen Akkord für die acht Stimmen. Ein geladenes Ratio-Preset ändert die Töne des Akkords, nie den Klang. Die Liste enthält auch eingebaute Akkorde. Ihr goldener Würfel würfelt einen Akkord in reinen Verhältnissen (Oktaven, Quinten, Terzen, Naturtöne); ihr rosa Würfel würfelt Verhältnisse irgendwo im Bereich („meist unbrauchbar, ab und zu etwas, das niemand geschrieben hätte“). Rechtsklick auf einen Würfel macht den Wurf rückgängig.

7. Die Engines

Die Seite Engine zeigt das Engine-Feld jeder Stimme. Jede Engine hat ein Vol (ihr Pegel in der Stimme) und ein KeyT (Key Tracking: bei 100 folgt die Engine der Note; bei 0 bleibt sie nahe C4, egal was Sie spielen – eine feste Tonhöhe oder Textur; dazwischen folgt sie weniger stark). Mehrere Tonhöhenregler haben einen Hz-Modus: Klicken Sie auf die Beschriftung (Semi, Pitch oder Cut), um stattdessen eine feste Frequenz einzustellen; ein erneuter Klick schaltet zurück. Im Hz-Modus gibt das Mausrad feine Schritte.

Klicken Sie auf den Titel einer Engine (ADD, IMPACT ...), um die Liste der Engines zu öffnen und sie zu wechseln: dieselbe Liste wie im Stimmenkopf. Nichts ändert sich, bis Sie wählen; ein zweiter Klick schließt die Liste. Die Engine einer stummgeschalteten Stimme wird blass.

Blättern. Die Graphen von Wave, den Tabellen von Shard, Impact, Sample und Noise haben zwei Pfeile, links und rechts: Sie blättern durch die Liste, ohne sie zu öffnen. Die Listen sind in Familien geordnet (bei Tabellen und Samples die Unterordner der Bibliothek).

Eigene Rezepte. Die Listen von Impact, Sample und Noise speichern ihre Einstellungen als Rezepte. Ändern Sie ein Rezept, zeigt die Liste Custom; in der rechten Spalte der Liste verwalten Save, Save As, Rename und Delete Ihre eigenen (die von Comma sind geschützt), und Recipes öffnet ihren Ordner. Ihre erscheinen in denselben Familien. Die Würfel ziehen nur aus denen von Comma.

Fehlende Dateien. Verlangt ein Preset eine Tabelle oder ein Sample, das Sie nicht haben, zeigt die Liste oder der Graph MISSING; fahren Sie mit der Maus darüber, um den Dateinamen zu lesen. Eine fehlende Tabelle spielt Basic.

Add

Die additive Engine: Die Stimme wird aus Teiltönen (Obertönen) aufgebaut, die jeweils einzeln berechnet werden. Auf diese Engine wirken die Stimmenseiten am feinsten, Teilton für Teilton.

Logic

Zwei Rechteckwellen, A und B, die ein Logikgatter zu einem einzigen Bit verknüpft.

Die Zeile unter den Haupt-Tabs wählt, was jeder Stimmenkörper anzeigt. Mangle

„Etwas, das alles zerlegt“: fünf Blöcke pro Stimme, nach den Warps und vor der Stimmenhüllkurve, für jede Engine. Jeder Block hat seinen eigenen Schalter und ist standardmäßig aus (ausgeschaltet berechnet er nichts). Die Tabs links zeigen jeweils einen Block (jede Stimme merkt sich ihren eigenen); der Punkt eines Tabs leuchtet, wenn sein Block bei dieser Stimme eingeschaltet ist. Jeder Block hat einen goldenen Würfel (spielbare Einstellungen) und einen rosa Würfel (beliebig); beide schalten den Block ein, Rechtsklick macht den Wurf rückgängig. Punch

Die letzte Stufe jeder Stimme, nach ihrer Hüllkurve und ihrer Attack-Ebene: ein Kompressor, dann zwei Regler, die den Anschlag jeder Note und das, was danach klingt, heben oder zähmen. Attack und Sustain haben keinen Schwellwert: Sie folgen der Form des Klangs, nicht seinem Pegel, und wirken auf einer leisen wie auf einer lauten Stimme gleich.

ReglerFunktion
AttackDer Anschlag, ±12 dB: eine schnelle Hüllkurve gegen eine langsame. Negativ zähmt eine Perkussion, die aus dem Mix ragt; positiv gibt einem weichen Klang mehr Biss.
SustainWas nach dem Anschlag klingt, ±12 dB, während der Klang abklingt: negativ strafft, positiv verlängert den Ausklang.
CompKomprimiert diese Stimme vor Attack und Sustain: Ein einziger Regler senkt den Schwellwert und erhöht die Ratio. Er senkt nur ab, was darüber liegt: Holen Sie den Pegel mit Gain zurück. 0 = aus.
AtkWie schnell der Comp den Pegel erfasst, 0,05 bis 50 ms. Kurz: Er erfasst die Spitzen, und der Anschlag wird gezähmt. Ab 5 ms: Der Anschlag kommt zuerst durch, dann wird der Körper niedergehalten, für mehr Biss.
RelWie schnell der Pegel zurückkehrt, 20 bis 1500 ms. Kurz: Er erholt sich zwischen den Spitzen. Ab 500 ms: Er kehrt langsam zwischen den Anschlägen zurück, das Pumpen.
GainHolt den Pegel nach dem Comp zurück, bis +24 dB. Nur bei eingeschaltetem Comp.
Peak, PumpZwei Ausgangspunkte für den Comp. Sie stellen Atk und Rel ein und sonst nichts; passen Sie diese danach an. Peak (0,05 ms / 50 ms) zähmt die Spitzen; Pump (5 ms / 500 ms) lässt den Anschlag durch und hält den Körper nieder.

Mit Attack, Sustain und Comp auf 0 passiert die Stimme unverändert. Die Attack-Ebene in Post durchläuft die Stufe mit der Stimme.

Route

Jede Stufe dieses Tabs hat eine Route:

  • All: die Stimmen und der Sub zusammen, nach dem Crush.
  • Voices: alle acht Stimmen, aber nicht der Sub, innerhalb der Stimmen (vor dem Crush).
  • V1-V8: nur innerhalb dieser Stimme, vor ihrer Lautstärke und Hüllkurve.
  • Group A, B, C: die Summe der Stimmen dieser Gruppe, nach ihrer Lautstärke und Hüllkurve, vor Voices und dem Crush.

Die Route öffnet ein Menü mit allen ihren Auswahlen (All, Voices — Group A, B, C — V1 bis V8), die aktuelle mit Häkchen.

Routing

Die Schaltfläche Routing (Tab EQ's/Filters, rechts neben der Presetliste) öffnet die Matrix ROUTING: eine Zeile pro Modul, in der Reihenfolge der Leiste, und eine Spalte pro Stelle, die es bearbeiten kann (All, Voices, A, B, C, V1-V8). Ein Punkt zeigt, wohin jedes Modul geht. Klicken Sie auf eine Zelle, um das Modul dorthin zu routen: Das ist dieselbe Einstellung wie die Route auf seiner Seite. Eine blasse Zeile ist ein ausgeschaltetes Modul; es lässt sich trotzdem routen.

11. Die FX-Leiste

Der Tab FX listet die Effekte auf seiner Leiste auf. 13. Modulation

Der schnellste Weg: Drag & Drop

Ziehen Sie eine beliebige Mod-Schaltfläche (die Leiste links im Tab Modulation oder die Mod-Kurzwahlen unten rechts in den anderen Tabs), eine Makro-Beschriftung (M1-M8) oder eine XY-Beschriftung auf einen Regler. Während Sie ziehen, öffnet das Verweilen über einem Tab oder einer Seitenschaltfläche diese; der Regler unter dem Mauszeiger leuchtet auf. Beim Loslassen entsteht eine Verbindung mit 100 %.

Ein modulierter Regler zeigt einen weißen Bogen (die Reichweite seiner Verbindungen) und einen farbigen Punkt pro Quelle. Um die Stärke zu ändern, klicken Sie mit der rechten Maustaste auf den Regler: Amount ±10 %, Invert sign, Set amount..., Remove link. Fahren Sie mit der Maus über eine Mod-Schaltfläche, eine Makro- oder XY-Beschriftung, um alles zu sehen, was sie bewegt.

Die 32 Quellen

Klicken Sie auf einen Mod in der Leiste, um ihn anzuzeigen; das kleine Feld am Anfang seiner Schaltfläche zeigt das Symbol seines Typs und schaltet ihn ein oder aus. Rechtsklick: eine Quelle kopieren / einfügen oder auf alle anderen kopieren. Der Typwahlschalter, mit denselben Symbolen, wählt den Typ; die Seite zeigt dann nur die Einstellungen dieses Typs.

Ein Mod, der auf sich selbst zielt, bewirkt nichts, und sein Feld wird blass.

Die Matrix

32 Verbindungen auf zwei Seiten (1-16, 17-32). Jede Verbindung: eine Quelle, ein Ziel und eine Stärke (-100 bis +100 %; negativ = in die andere Richtung). Der Schalter O / I oben schaltet alle Verbindungen ein oder aus; die Quellen laufen weiter.

Quellen: Mod 1-32, Macro 1-8, Vel (Anschlagdynamik jeder Note), Vel Hold (beim Note-on eingefroren), Mod Wheel, XY X, XY Y.

Die Ziele sind im Zielmenü nach Bereichen gruppiert (Voices, Global, jede Engine, jede Seite, der Mangle, jeder Filter und Effekt, die Mods selbst, die Matrix-Stärken ...). Stimmenbezogene Ziele gibt es für V1 bis V8. Ein Ziel verwendet in der Regel das Wort, das Sie auf dem Regler lesen, ausgeschrieben, nach seinem Bereich und seiner Stimme (Pluck Decay V1); die Automationslisten Ihres Hosts verwenden dieselben Wörter.

Ist die Quelle ein Makro, macht eine Schaltfläche neben der Stärke es bipolar (Mitte = null, wirkt in beide Richtungen). Diese Eigenschaft gehört zum Makro: Alle seine Verbindungen folgen ihr.

Makros

Acht Drehregler, M1-M8. Ziehen Sie die Beschriftung eines Makros auf Regler, um es zu verbinden. Ein Makro übernimmt den Namen seines ersten Ziels; ein Doppelklick auf die Beschriftung benennt es um (ein | erzwingt einen Zeilenumbruch). Rechtsklick auf den Drehregler: Bipolar, oder alle seine Verbindungen entfernen. Doppelklick auf den Drehregler: zurück in die Ruhestellung.

XY-Pad

Im Tab Modulation. Ziehen Sie den Punkt: Seine beiden Achsen sind Quellen. Die Mitte ist die Ruhestellung (dort wird nichts moduliert); Doppelklick zentriert neu. Die Beschriftungen X und Y lassen sich auf Regler ziehen, übernehmen den Namen dessen, was sie steuern, lassen sich per Doppelklick umbenennen, und eine auf einer Beschriftung abgelegte Quelle moduliert diese Achse.

Mod-Kurzwahlen

Unten rechts in den Tabs Synthesis, EQ's/Filters und FX: Mod 1-16 oder 17-32 (die beiden Schaltflächen links). Ziehen Sie eine davon auf einen Regler. Eine belegte Kurzwahl leuchtet; fahren Sie mit der Maus darüber, um ihre Verbindungen zu lesen.

14. Spielen: Tastatur, Akkorde, Skala

K -- die Tastatur

Klicken Sie unten links auf K. Die Bildschirmtastatur spielt Comma (auch Ihre Computertastatur, solange diese Leiste angezeigt wird). Das Pitchbend-Rad federt in die Mitte zurück; das Modulationsrad bleibt, wo Sie es loslassen (es folgt CC1 Ihres MIDI-Keyboards; routen Sie es mit der Quelle Mod Wheel). Die beiden kleinen Felder stellen den Bend-Bereich nach oben und unten ein (in Halbtönen).

Die Tastatur öffnet sich auf C1 und lässt sich von C0 bis C8 verschieben (C2 = MIDI-Note 48, 130,81 Hz, wie in Bitwig). Ziehen Sie über ihren linken oder rechten Rand hinaus, um sie zu verschieben, je weiter, desto schneller; auch das Mausrad verschiebt sie. Die Pfeile an beiden Enden leuchten, wenn in dieser Richtung weitere Noten liegen: Ein Klick springt eine Oktave. Auf der Computertastatur spielt A das C2, W C#2, S D2 ... bis K, C3. Vel 78: Leuchtet es, spielt jede Taste der Bildschirmtastatur mit 78,7 % Velocity (Bitwigs Standard), wo immer Sie klicken; aus: Je höher Sie auf eine Taste klicken, desto leiser spielt sie. Ein MIDI-Controller behält seine eigene Velocity.

Die aufrecht stehende Schaltfläche Hold hält die Note: Solange sie leuchtet, warten losgelassene Tasten (der Bildschirmtastatur oder per MIDI) und wirken erst, wenn sie ausgeht; eine noch gedrückte Taste klingt weiter. Das Sustain-Pedal (CC64) bewirkt dasselbe, solange es getreten ist, und lässt Hold leuchten. Hold bleibt an, wenn Sie zu M oder C wechseln: Die Noten klingen weiter, und K leuchtet.

All Sound Off (CC120) bringt Comma sofort zum Schweigen, Release und Effektfahnen eingeschlossen (in 10 ms, ohne Klick). All Notes Off (CC123) lässt die Noten los und die Fahnen ausklingen.

C -- die Akkordfolge

Acht Schritte. Klicken Sie auf die Nummer eines Schritts, um ihn ein- oder auszuschalten, auf seine Stufe, um I bis VII der Skala zu wählen, und darunter, um den Akkord zu wählen (Major, Minor, Dim, Aug, Sus2, Sus4, 6, m6, 7, Maj7, m7, m7b5, dim7, 9, m9, Maj9, add9 oder ein Ratio-Preset). Ist Prog eingeschaltet, übernimmt jede gespielte Note den nächsten aktiven Schritt: um seine Stufe verschoben, mit seinem Akkord gespielt. Wird mit dem Preset gespeichert.

Skala

Scale oben: Wählen Sie einen Grundton (C bis B) und eine Skala (Off, Major, Minor, Harmonic Minor, Dorian, Phrygian, Lydian, Mixolydian, Locrian, Pentatonic Major, Pentatonic Minor, Blues). Jede gespielte Note rückt auf den nächstgelegenen Ton der Skala (bei Gleichstand nach unten). Wird mit dem Preset gespeichert.

Rec -- den Ausgang aufnehmen

Rec in der Ausgangsspalte öffnet den Rekorder: ein kleines Fenster, das von Seite zu Seite offen bleibt. Es macht aus dem gesamten Ausgang von Comma ein Sample, auf eine von zwei Arten:

  • Last seconds: was Sie gerade gespielt haben. Keep last seconds speichert es; Length (1 bis 29 s) gibt an, wie weit es zurückreicht.
  • Next note: Arm, dann spielen. Die Aufnahme beginnt mit Ihrer nächsten Note und endet, wenn der Klang verklungen ist (Effektfahnen eingeschlossen), oder bei Length. Ein erneuter Klick auf dieselbe Schaltfläche bricht ab oder beendet eine Aufnahme.

Die Schaltfläche Rec ist bernsteinfarben, wenn sie scharf geschaltet ist, rot während der Aufnahme. Das Sample wird beschnitten, ein- und ausgeblendet und auf -1 dB gebracht; dann geben Sie ihm einen Namen und wählen seinen Ordner in Samples (Captures, Kick, Snare, Hat, Clap, Perc, Texture oder einen neuen). Folder öffnet den Ordner Samples. Jeder dieser Ordner ist eine Familie in den Menüs der Engine Sample und der Attack-Ebene.

Die Presetliste (obere Leiste)

Wählen Sie ein Preset, um es zu laden; die Pfeile wechseln zum vorherigen / nächsten. Ihr Menü enthält außerdem Save, Save As, Reload, Rename, Delete und Init (Init lädt DeFaUlT, den Klang, mit dem Comma startet). Ein * vor dem Namen bedeutet, dass der Klang seit dem Laden verändert wurde.

Save As geht vom geladenen Preset aus, um Versionen davon zu speichern: sein Name mit einer Version mehr (Strong Enough wird Strong Enough v2, dann v3 ...) und seine Category, Type und Color; die Note beginnt leer. Von DeFaUlT aus wird nichts übernommen.

Die Liste zeigt die Presets des im Tab Presets gewählten Ordners samt Unterordnern (All presets: die ganze Bank); die Pfeile durchlaufen diese Liste. Ein anderswo geladenes Preset behält seinen Namen im Feld.

Dieses Menü hat drei Spalten, wie die Menüs der anderen Bänke und der nach Familien sortierten Listen (Ratio-Presets, EQ- und Filter-Presets, Wavetables, die Listen von Impact, Noise, Sample und Attack). Links die Familien, aus den Unterordnern gebildet: Ein Klick ändert die mittlere Spalte und lässt das Menü offen. In der Mitte der Inhalt dieser Familie, das aktuelle Element hervorgehoben. 16. Die Würfel

Würfel finden Sie überall in Comma. Die Konvention ist immer dieselbe:

  • Goldener Würfel: ein spielbarer Wurf – gezähmte Werte oder ein anderes Element derselben Bank oder Kategorie.
  • Rosa Würfel: beliebig – der gesamte Bereich, für glückliche Zufälle.
  • Silberner Würfel (Stimmenkopf): nur die Engine.
  • Rechtsklick auf einen beliebigen Würfel: zurück zum Zustand vor dem Wurf.

Sie finden sie an der Presetliste, den Ratio-Presets, jedem Stimmenkopf, den Engines Add, Chaos und Logic, den Listen von Impact, Noise, Sample und Attack, bei Spectron, jedem Warp-Slot, jedem Mangle-Block, jeder EQ- und Filterbank, den Sidechain-Formen, den Mod-Kurven und dem Step-Sequenzer.

Mutate ist der sanfte Verwandte der Würfel: Statt einen neuen Klang zu würfeln, verschiebt es jeden stufenlosen Regler des Patches ein wenig um seinen aktuellen Wert. Die Box daneben bestimmt, wie weit: Subtle, Medium oder Wild. Darunter eine Ausrichtung: Electrize (Cyber, Techno, New Wave) mutiert wie Medium und schiebt den Klang dann in diese Richtung. Listen, Schalter, Engines, Routings, Verhältnisse, Tonhöhen, Ausgangspegel und die beiden Velocity-Regler bewegen sich nie; die Master-Hüllkurve bewegt sich nur in Wild. Und ein Regler auf null oder an einem Ende seines Wegs bleibt dort -- was Sie ausgeschaltet haben, bleibt aus. Erneut klicken, um weiter zu wandern; Rechtsklick: zurück zu den Werten vor der letzten Mutation. Die Änderung geschieht während einer kurzen Stille (etwa 75 ms), damit eine gehaltene Note nicht springt.

Signalfluss

Jede Stimme: engine (+ Attack Pre) -> Diss -> Warp 1 -> Warp 2 -> Mangle (Stutter, Shaper, Rate, Mod, Disperse) -> Pluck / Motion / Spectron / Capture -> [Module auf diese Stimme geroutet] -> Env x Vol -> pan (+ Attack Post) -> Punch (Comp, dann Attack und Sustain) Gruppen: Summe der Stimmen von A, B, C -> [Module auf diese Gruppe geroutet] Stimmen: Summe von V1-V8 -> [Module auf Voices geroutet] Mischung: Stimmen + Sub -> Master-Hüllkurve (Global) Danach: Crush -> Spatial (Width, M/S) -> [Module auf All geroutet] -> FX-Leiste in Ihrer Reihenfolge -> Sidechain (falls zuletzt) -> Dynamics -> Master -> Limiter -> Ausgang

Bei einer Add-Stimme wirken Pluck, Motion, Spectron und Capture auf jeden Teilton, während der Synthese: Warp und Mangle kommen dort danach.

Die Module sind die zehn des Tabs EQ's/Filters (EQ A-D, F1-F4, Warmth, Modal). Jedes geht dorthin, wohin seine Route zeigt, und sie laufen immer in der Reihenfolge ihrer Leiste: Ziehen Sie eine Leistenschaltfläche, um sie zu ändern. Ist Warmth auf All geroutet, läuft Dist ganz oben in der FX-Leiste vor Warmth; weiter unten in der Leiste danach.

Tipps

  • Comma ist monophon: Um Akkorde zu spielen, stellen Sie die Verhältnisse ein (oder verwenden Sie die Ratio-Presets oder die Akkordfolge).
  • Eine Empty-Stimme kostet nichts, und eine ausgeschaltete Stufe berechnet nichts. Behalten Sie die CPU-Anzeige im Blick.
  • Abtastrate: 44,1 oder 48 kHz empfohlen, 96 kHz möglich. Die Last folgt der Rate: Bei 192 kHz können die schwersten Presets einen ganzen Kern belegen.
  • Stellen Sie Pegel mit der Anzeige im LUFS-Modus ein (die weiße Linie liegt bei -17), und vergleichen Sie die Effekte mit FX Off.
